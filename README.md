# 🌍 ForeignSkills

**ForeignSkills** — это учебный frontend-проект для изучения иностранных языков.  
Приложение позволяет пользователю зарегистрироваться, войти в аккаунт, изучать материалы в формате карточек и проходить тесты для проверки знаний.

Проект разработан на **Vue 3** и **Vite**, а для хранения данных и авторизации используется **Supabase**.

---

## 📌 О проекте

ForeignSkills — это веб-приложение, ориентированное на самостоятельное изучение иностранных языков.

Основная идея проекта — объединить в одном интерфейсе:

- информационную главную страницу;
- регистрацию и авторизацию пользователя;
- учебные карточки;
- рубрики для фильтрации материалов;
- тесты по темам;
- страницу прохождения теста;
- подсчёт правильных и неправильных ответов;
- работу с удалёнными данными через Supabase.

Проект подходит как учебная курсовая работа и как демонстрация базовых навыков разработки SPA-приложения на Vue.

## 🧩 Основные разделы

### Главная страница

Главная страница знакомит пользователя с проектом и показывает преимущества изучения иностранных языков.

На ней размещены:

- крупный приветственный блок;
- кнопка начала обучения;
- блоки о преимуществах изучения языков;
- переходы к основным возможностям проекта.

---

### Карточки

Раздел карточек предназначен для изучения материалов.

Данные загружаются из Supabase:

- список рубрик берётся из таблицы `rubrics`;
- список карточек берётся из таблицы `cards`;
- при выборе рубрики карточки фильтруются по полю `rubric`.

---

### Тесты

Раздел тестов показывает список доступных тестов.

Данные загружаются из Supabase:

- рубрики берутся из таблицы `rubrics`;
- тесты берутся из таблицы `tests`;
- тесты можно фильтровать по рубрике;
- выбранный тест открывается на отдельной странице.

---

### Страница прохождения теста

На странице теста пользователь отвечает на вопросы по выбранной теме.

Реализовано:

- загрузка информации о тесте;
- загрузка вопросов из таблицы `questions`;
- загрузка ответов из связанной таблицы `answers`;
- выбор одного ответа;
- отображение результата ответа: правильно или неправильно;
- переход к следующему вопросу;
- подсчёт правильных и неправильных ответов;
- вывод итогового результата;
- повторное прохождение теста.

---

### Регистрация

На странице регистрации пользователь вводит:

- nickname;
- email;
- пароль;
- подтверждение пароля.

После успешной регистрации пользователь создаётся через Supabase Auth, а дополнительные данные записываются в таблицу `users`.

---

### Авторизация

На странице входа пользователь вводит:

- email;
- пароль.

После успешной авторизации выполняется переход на страницу ученика.

---

## 🔐 Supabase

Проект использует Supabase для:

- авторизации пользователей;
- регистрации пользователей;
- входа в аккаунт;
- хранения карточек;
- хранения рубрик;
- хранения тестов;
- хранения вопросов;
- хранения ответов.

Подключение к Supabase находится в файле:

```text
src/lib/supabase.js
```

В проекте используются переменные окружения:

```env
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

---

## 🗄️ Ожидаемые таблицы Supabase

По коду проекта используются следующие таблицы:

| Таблица | Назначение |
|---|---|
| `users` | Данные пользователей |
| `rubrics` | Рубрики для карточек и тестов |
| `cards` | Учебные карточки |
| `tests` | Тесты |
| `questions` | Вопросы тестов |
| `answers` | Варианты ответов |

## 🚀 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/NINDP/ForeignSkills.git
cd ForeignSkills
```

### 2. Установка зависимостей

```bash
npm install
```

### 3. Создание файла окружения

В корне проекта создайте файл:

```text
.env
```

Добавьте в него данные Supabase:

```env
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### 4. Запуск в режиме разработки

```bash
npm run dev
```

После запуска Vite покажет локальный адрес приложения, например:

```text
http://localhost:5173
```

## ⚠️ Важное замечание по безопасности

В проекте используется Supabase, поэтому ключи и адрес проекта должны храниться в `.env`.

Не рекомендуется публиковать приватные ключи Supabase в репозитории.

Также при дальнейшей доработке проекта лучше хранить только безопасные пользовательские данные в таблице `users`, а пароли оставлять на стороне Supabase Auth.
